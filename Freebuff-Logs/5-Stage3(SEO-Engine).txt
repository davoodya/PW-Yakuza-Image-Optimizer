## Stage 3 Complete ✅ — SEO Engine

**What was built (`includes/seo.php`):**
- **`yio_apply_seo_optimization()`** — self-gating entry point (skips when `seo_enable` is off or no feature is active), wrapped in try/catch so it can never break the upload pipeline.
- **Metadata stripping** — removes EXIF/IPTC/XMP (+ 8bim/photoshop) profiles while deliberately **keeping the ICC color profile**, so stripping camera data never shifts colors.
- **Deterministic jitter** — brightness, contrast, and color (saturation) variation derived from a per-image seed = `attachment_id + wp_hash(file_path)`. This gives the killer property for your SEO goal: *the same image on the same install always gets the same jitter (reproducible), while a copy of it on any other install gets different jitter* — so a stolen/reused image becomes perceptually unique per site. Brightness+color run in one `modulateImage` pass (100 = neutral, ±3% typical); contrast uses `brightnessContrastImage` on the ±100 scale.
- **Gaussian noise** — full-strength noise is generated on a clone, then faded via alpha multiplication (`noise_strength` is in tenths of a percent: 6 → 0.6%), and blended. The image's own transparency is preserved — validated that transparent PNG regions stay perfectly clean.

**Cross-cutting fix (from review):** moved alpha-channel cleanup to the *pipeline* — the source's transparency is captured at load and, before conversion, any alpha the watermark or noise engines introduced on opaque sources (JPEGs) is removed so WebP/AVIF output stays lean.
