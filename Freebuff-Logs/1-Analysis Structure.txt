## 4. Bugs & Issues Found

1. **UTF-8 BOM in every file** (`﻿<?php`). This is the most serious latent bug — a BOM before `<?php` can cause *"headers already sent"* warnings and corrupt output. Every file needs the BOM stripped (I verified it in all 13 PHP files).
2. **Dead init calls in the main file**: `yio_logger_init()` is called but never defined (logger.php only has `yio_log`), and `yio_bulk_init()` points to a file that doesn't exist. Both are guarded by `function_exists()` so they don't fatal, but they're misleading.
3. **Duplicate `'background_processing' => 1` key** in `yio_default_settings()` (settings.php, Batch section).
4. **Inconsistent `max_width` default**: `2000` in settings.php vs `1500` fallback in `admin/seo.php`.
5. **`watermark_image` sanitized with `sanitize_text_field`** but it's actually an attachment ID — should be `absint`.
6. **The pipeline never calls the engines**: `yio_process_uploaded_image` has a "Backup Placeholder" and "Optimization Placeholder" but never invokes `yio_create_backup()`, `yio_apply_watermark()`, or `yio_apply_seo_optimization()`.
7. **Settings defined but unused**: `restore_method`, `image_comparison`, `include_webp`, `bulk_limit`, `dry_run` have no consuming code yet.
8. **Single global `<form>` wraps all tabs** — this will conflict when Backup/Bulk tabs need their own action forms (restore, run-bulk buttons).

## 5. Suggested Development Roadmap

1. **Core processing pipeline** — rewrite `image-processor.php` to: backup original → smart-resize → auto-orient → watermark → SEO jitter/noise → convert to WebP/AVIF → update attachment metadata (and swap file extension in the DB).
2. **Watermark engine** — Imagick composite for PNG stamps + `annotateImage` for text, honoring scale/opacity/position/padding.
3. **SEO engine** — strip EXIF/IPCC/XMP, deterministic-but-random jitter (brightness/contrast/color), Gaussian noise, auto-orientation.
4. **Bulk optimizer** (`bulk.php` + `restore.php`) — scan attachment library, batched background processing, restore-from-backup.
5. **Hardening** — strip BOMs, fix dead init calls, real `uninstall.php`, add `yio_logger_init()`, duplicate-key cleanup.
